# CodeAlpha C++ Internship

This repository contains all the projects and tasks completed during my **C++ Internship at CodeAlpha**.

The internship provided hands-on experience in C++ programming, problem-solving, Data Structures and Algorithms, and developing practical console-based applications.

## Internship Details

- **Organization:** CodeAlpha
- **Internship Domain:** C++ Programming
- **Role:** C++ Intern
- **Programming Language:** C++

## Projects / Tasks

### Task 1 – CGPA Calculator

A C++ program that calculates the GPA/CGPA of a student based on course grades and credit hours.

**Key Concepts:**
- Functions
- Arrays
- Loops
- Conditional Statements
- GPA/CGPA Calculation

---

### Task 2 – Login and Registration System 

A console-based login and registration system developed in C++. The system allows users to register an account and securely log in using their credentials.

**Key Concepts:**
- Functions
- File Handling
- String Handling
- User Authentication
- Input Validation

---

### Task 3 – Sudoku Solver

A C++ program that solves Sudoku puzzles using an efficient backtracking approach. The program finds a valid solution by systematically trying possible numbers.

**Key Concepts:**
- Backtracking
- Recursion
- 2D Arrays
- Functions
- Problem Solving
- Data Structures and Algorithms

---

### Task 4 – Banking System

A console-based banking application developed in C++ that provides basic banking operations such as creating accounts, depositing money, withdrawing money, and checking account details.

**Key Concepts:**
- Functions
- Classes and Objects
- File Handling
- Data Management
- Conditional Statements
- Object-Oriented Programming
